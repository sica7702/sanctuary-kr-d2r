Sanctuary KR · Image Appraisal v44
Affix Coverage / OCR / Manual Fallback Audit

핵심 변경
1) 인게임 한글 명칭 '마력'을 정식 옵션명으로 전환 (에너지/energy는 검색 별칭 유지)
2) 활력 / 모든 능력치 추가
3) 공격 오라 / 방어 오라 / 성기사 전투 / 야만용사 전투 / 악마술사 혼돈·기괴·악마 탭 OCR 직접 규칙 추가
4) 인장/충전 표기(예: 4 레벨 인장: 무기력 (충전 n/n회))를 '충전 기술'로 보존
5) 받은 피해의 마나 전환 / 최대 마나·생명력 증가 / 결빙되지 않음 등 누락 안전 옵션 추가
6) 대상 감속 / 몬스터 도주 / 대상 빙결 / 공격자가 받는 번개 피해 / 명중 시 시야 감소 등 무기·방어구 저빈도 옵션 카탈로그 확장
7) 전체 수동 옵션 검색은 부위 권장 여부와 무관하게 전체 defs를 검색
8) 이미지 감정 페이지 진입 시 BETA/개발중 안내 모달 표시 + 오늘 하루 보지 않기

설계 원칙
- OCR 전용 정밀 규칙 -> 복합 문맥 -> 일반 규칙 -> 전체 별칭 fallback -> 수동 전체 카탈로그 순으로 처리.
- 가치 엔진에 아직 별도 프리미엄 점수가 없는 저빈도 옵션도 수동 입력을 막지 않음.
- 스태프모드/충전 기술은 스킬명이 매우 많아 일반 카테고리로 보존하고, 추후 개별 스킬 시장가중치 레이어에서 세분화 가능.
