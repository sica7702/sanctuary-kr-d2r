Sanctuary KR · Build Demand Matrix v47

공통 적용 영역
- 레어템 이미지 감정
- 아이템 감정 DB

핵심 변경
1) 범용 접사 품질/고가 아키타입 점수와 특정 빌드 수요 점수를 분리.
2) 이미지 감정은 OCR 확정 옵션을 Build Demand Matrix에 다시 투입해 Top 3 수요 빌드를 자동 추론.
3) 아이템 감정 DB도 사용자가 선택한 빌드만 보는 방식에서 벗어나 현재 입력 옵션으로 전체 빌드 수요를 자동 추론.
4) 특정 빌드 수요가 강한 레어는 범용 점수가 낮아도 실사용/거래 가능성을 별도로 표시.
5) 단, 빌드 적합도만으로 낮은 롤 아이템을 트로피급으로 올리지는 않도록 품질 점수와 상한을 분리.
