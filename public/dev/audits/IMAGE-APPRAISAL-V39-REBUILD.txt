Sanctuary KR · Image Appraisal v39 FULL REBUILD
2026-09-09

핵심 변경
1) 감정 엔진을 OCR과 분리
- OCR은 문자/숫자 인식만 담당.
- 사용자가 수동 보정한 값은 OCR 결과보다 우선.

2) 레어 득환 DB 직접 연동
- archive/rare-data.js의 98개 레어 득환 기록을 감정 근거 레이어로 사용.
- 부위별 고가 패턴, tier, market, sources를 결과 화면에 표시.
- 현재 항목과 가장 가까운 상위 거래군을 찾고 충족/결손을 분리 출력.

3) 부위별 전문 평가
- 반지 / 목걸이 / 써클릿 / 장갑 / 부츠 / 벨트
- 갑옷 / 방패 / 무기 / 활 / 자벨린 / 클러 / 오브 / 완드 / 셉터 / 직업 전용
- 동일 옵션이라도 부위별 핵심도가 다르게 반영됨.

4) OCR 정규화 재작성
- 4-pass: 2.4x 원본 / 3x 대비 / 3x D2R 글자색 마스크 / 3x 이진화.
- 같은 pass의 인접 2~3줄을 문맥 후보로 재조립.
- 적중당 마나/생명력 훔침, 마나 재생을 일반 마나/생명력과 먼저 분리.
- 요구레벨/방어력/내구도 같은 메타 숫자는 옵션 후보에서 제외.
- 부위 허용 옵션 및 DB 최대치 초과 후보 제거.

5) 수동 보정 UX
- datalist 텍스트 입력 대신 실제 select 옵션 목록 제공.
- OCR 오인식 시 옵션명을 바로 선택 가능.
- 수정값 기준으로 전문 감정 재실행.

6) 써클릿 소켓 가치
- 2소켓 여부를 고가 패턴의 필수축으로 직접 평가.
- 0/1솟 또는 미확인 시 상위 거래군 대비 핵심 결손으로 먼저 설명.

7) 결과 구조
- 종합 점수 / 시장 포지션
- OCR 신뢰도 / 정규화 신뢰도 / 롤 품질 / DB 패턴 일치도
- 왜 가치가 있는가 / 어디서 쓰는가 / 정확히 무엇이 아쉬운가
- 가장 가까운 고가 패턴 / 현재 충족 / 상위군 대비 결손
- Rare DB 시장 메모 및 교차검증 source 표시

시장 데이터 주의
- 현재 v39는 Rare DB에 이미 교차검증된 Traderie/d2jsp/Inven/Diablo2.io 등의 거래 패턴을 사용.
- 판매중 단일 호가를 실제 체결가로 간주하지 않음.
- Traderie 실시간 체결/매물 자동 수집은 브라우저 정적 사이트와 분리된 서버/API 계층이 필요하므로 v39에서는 '실시간 가격 숫자'를 억지로 출력하지 않음.
