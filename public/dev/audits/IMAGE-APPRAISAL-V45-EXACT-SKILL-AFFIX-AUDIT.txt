v45 changes
- Charged skills are no longer normalized to a single generic "충전 기술" result when a skill name is readable.
- OCR now preserves the literal skill string: e.g. "4 레벨 인장: 무기력 (충전 7/30회)" -> "충전 기술 · 인장: 무기력 / Lv4".
- Teleport charges likewise become "충전 기술 · 순간이동" when Korean OCR reads that text.
- Known charged-skill catalog added to the searchable manual option pool, with English aliases for search/cross-check.
- If charge context is found but the skill name itself is unreadable, automatic normalization rejects the generic result and asks for manual exact-skill selection instead of silently accepting an ambiguous option.
- Item Appraisal DB gains exact charged-skill name, skill level, max charge count, exact proc skill name, proc level, proc chance, and trigger fields on eligible rare/crafted item families.
- Image appraisal BETA notice key advanced to v45 and pageshow handling added so the notice appears on the new version unless the user explicitly selects "오늘 하루 보지 않기".

Important
The exact Korean localization of a charged skill is preserved directly from OCR whenever possible. The manual catalog also keeps English aliases because localization can differ by client/version and current RotW-era data evolves independently of legacy LoD tables.
