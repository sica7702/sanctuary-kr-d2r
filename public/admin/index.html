공개 시장 자동 수집

매시간 외부 페이지를 1개씩 저빈도 처리합니다. 공개 HTTPS 페이지만 GET하며 robots.txt를 확인하고, 로그인·403/429 우회는 하지 않습니다. 한 Worker 요청은 외부 페이지 1개만 처리합니다. HTTP 200이어도 실제 거래 본문이 없으면 획득 실패로 분류합니다. Playnote는 장신구/장갑/부츠/무기 등 희귀 후보를 우선 수집합니다. 강제 재처리 시 실제 공개 레어 상세 3건을 검증용 bootstrap으로 함께 큐잉하며, 구조화된 시장관측은 자동 활성화 없이 검수 대기에만 등록합니다. d2jsp는 이 자동 수집기에 포함되지 않습니다.
