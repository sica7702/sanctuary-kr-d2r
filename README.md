# Sanctuary KR AI 감정 시스템

## MVP 입력

아이템 스크린샷 1장과 선택적 텍스트, 아이템 종류, 부위, 게임 환경 정보를 입력받는다.

## MVP 판정

입력된 OCR 결과와 수동 옵션을 구조화하고, 기존 감정 엔진을 보존한 상태에서 옵션 분류, 가치 등급, 검수 필요 여부를 판단한다.

## MVP 출력

자유문장이 아닌 구조화된 결과를 출력한다.

- 아이템 종류
- 아이템 부위
- 정규화된 옵션 목록
- 옵션별 수치
- 가치 등급
- 검수 상태
- 판정 근거
- 신뢰도
- 모델 버전
- 알고리즘 버전

## 불확실성 처리

OCR 결과가 누락되었거나 옵션이 중복·충돌하거나 지원 범위를 벗어나면 자동 판정하지 않고 기존 감정 결과를 보존하거나 사람 검수로 보낸다.

## 기존 기능 보호

다음 기능은 MVP 정의 단계에서 수정하지 않는다.

- 기존 OCR 인식 엔진
- 기존 수동 감정 엔진
- 기존 옵션 점수 계산
- `worker.js`
- `wrangler.jsonc`
- `public/archive/**`
- 기존 테스트와 Cloudflare 라우팅

## MVP 완료 조건

- 입력·판정·출력 형식이 문서화되어 있다.
- 기존 감정 기능이 삭제되거나 대체되지 않는다.
- 불확실한 입력을 자동으로 확정하지 않는다.
- 판정 이유와 버전 정보가 남는다.
- 기존 테스트가 통과한다.
