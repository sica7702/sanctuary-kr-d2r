# Chapter 04 입력 OCR 검증 범위

## 목표

이미지 입력과 OCR 결과를 검증하고, 불확실하거나 충돌하는 결과는 자동 감정하지 않는다.

## 기존 OCR 보호

- 기존 OCR 인식 엔진은 수정하지 않는다.
- 기존 OCR 런타임과 학습 데이터는 변경하지 않는다.
- 기존 OCR 화면과 사용 흐름은 변경하지 않는다.
- 이번 챕터는 검증과 보류 판정만 추가한다.

## 입력 검증

- 이미지가 존재해야 한다.
- 손상된 이미지와 지원하지 않는 형식은 거부한다.
- 이미지 크기가 비정상적으로 작으면 재입력을 요청한다.
- OCR 원문이 비어 있으면 자동 감정하지 않는다.
- OCR 결과에는 원문과 신뢰도 정보를 보존한다.

## OCR 불확실성

- 해석되지 않은 줄은 삭제하지 않는다.
- 해석되지 않은 줄은 unresolved_options에 보존한다.
- 옵션 값이 숫자로 해석되지 않으면 검수 필요로 보낸다.
- 같은 옵션이 중복되면 자동 합산하지 않는다.
- OCR 결과와 수동 입력이 다르면 충돌 상태로 기록한다.

## 이미지·OCR 충돌

- 원본 이미지와 OCR 결과가 충돌하면 자동 확정하지 않는다.
- 충돌 결과는 human_review 상태로 보낸다.
- 기존 감정 결과가 있는 경우 기존 결과를 보존한다.
- AI 모델은 충돌이 해결되기 전까지 가치 등급을 덮어쓰지 않는다.

## 자동 처리 금지 조건

- 이미지 손상
- OCR 원문 없음
- 옵션 중복
- 옵션 값 불명확
- 이미지와 OCR 불일치
- 지원 범위 밖 아이템
- 요구 레벨 또는 부위 정보 충돌

## Chapter 04 완료 조건

- 입력 검증 규칙이 문서화되어 있다.
- OCR 불확실성 처리 규칙이 문서화되어 있다.
- 이미지와 OCR 충돌 처리 규칙이 문서화되어 있다.
- 기존 OCR 엔진 파일이 변경되지 않았다.
- 정상 OCR 결과와 불확실한 OCR 결과를 구분할 수 있다.
